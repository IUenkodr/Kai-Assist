# Kai-Assist: Spatial Intelligence Interface

Kai-Assist is a next-generation autonomous operating environment that orchestrates Linux sandboxes through a spatial intelligence layer.

## Architecture
- **Control Plane**: Kai-Daemon managing PTYs and system resources.
- **Interaction Plane**: A fluid AI-Canvas and Assistant Overlay.

## Core Features
- **AI-Canvas**: 2D spatial coordinate system for linked functional objects.
- **Assistant Overlay**: Gemini-like slide-up command hub.
- **PTY Engine**: Live mirror of sandbox processes.
- **Multi-Distro**: Support for Debian, Alpine, WolfiOS, and Arch Linux.
